# R2T2 CrispASR Implementation Plan

> Implementation is inline using executing-plans. Independent read-only review follows requesting-code-review. The user authorized GitHub publication and commits on 2026-10-03.

**Goal:** Installable local R2T2 transcription plugins for Windows and macOS.

**Architecture:** Native platform adapters own a pinned, loopback-only CrispASR
process. Both implement its realtime JSON protocol and checksum-verified model
management. Packaging builds against pinned upstream TypeWhisper SDK contracts.

**Tech Stack:** C#/.NET 10, Swift 6, C++/CMake, Python 3 build tooling, unittest,
and xUnit/Swift Testing transport tests.

## File boundaries

- `assets/models.json`: one pinned model catalogue shared by both platforms.
- `tools/build.py`: fetch pinned sources, apply checked patch, build/package.
- `runtime/`: loopback patch and native parent watchdog.
- `windows/`: SDK adapter, model store, process owner, WebSocket session, tests.
- `macos/`: corresponding Swift components and focused Swift tests.
- `tests/`: Python build/patch and real-model protocol probes.
- `.github/workflows/build.yml`: platform builds, tests and artifacts.
